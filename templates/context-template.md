# Context

Entry point for `context/` — everything about the actual project:
mission, techstack, architecture, conventions, terminology, and however
many additional files make sense for this project's actual moving
parts. No fixed subfolder convention — name and organize additional
files by whatever groups the project naturally: an architectural layer,
a feature-level concept, a domain area. "Module" here means a
conceptual group of moving parts that make up a feature, not a
coding-language module or a folder of classes.
